So nothing here surprises you. These run through the dashboard's own tools, with the default Claude account, and do not ask:

  • On the BETA site Claude can run commands as the beta's own user (the beta is a copy, not your live site).
  • After a change is saved and its tests pass, the dashboard puts it on beta by itself. If the project has no beta yet, it first makes one — Claude builds the site — and copies your live data into it.
  • While you press Go Live and a release step fails, Claude may fix it by running install / build commands in the new release as the live site's own user, and it saves the corrected steps that later Go Lives replay.
  • Beta, release and live-steps runs have their own tool set (not the chat's) and use the default Claude account, with web search / fetch open.
