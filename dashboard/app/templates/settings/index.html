Claude accounts

Every Claude account signs in through the web — no tokens. Add as many as you like, each with its own name: in the chat you pick which account (and which of its models) works on a message. Each account stays logged in: the dashboard checks it every hour and renews it by itself; if one ever logs out you get an alert. The default account is pre-selected in the chat and also does the beta, release and live-steps work.

Know the risk. Each login is a full login to that Claude account, kept in the server user's home. Anything that runs as that user — Claude's commands, a project's tests, package installs — could read it and use it from anywhere until you revoke it (claude.ai → Settings). On a project whose chat has a client's or developer's message, web search / fetch and every connector call ask you first.
